# Opheliadex

Ophelia's personal site, deployed on Netlify. Every push to `main` deploys to https://opheliadex.com.

| Page | File |
|---|---|
| Homepage | `public/index.html` |
| Birthday invite + RSVP form | `public/birthday/index.html` |
| RSVP thank-you page | `public/birthday/thanks/index.html` |
| Shared styles | `public/styles.css` |
| Party theme (sky, balloons, envelope) | `public/party.css`, `public/party.js` |
| Homepage styles | `public/home.css` |
| Photos / images | `public/images/` |

RSVPs are collected with Netlify Forms (form name `rsvp`) and appear in the Netlify dashboard under **Forms**.

The site is kept out of search engines (`robots.txt` and `noindex` tags), and the invite page is not linked from the homepage.
